# 10×10 tile 逐拍走一遍（每步都有数）

> 用一个 tile 把 **dw3×3 → 逐通道 12 拍 → 1×1 点卷积 → 量化 → 池化** 全走一遍。
> 数据全部来自仿真（`mb2_tb` 逐字节比对通过的那一版）。
> 例：`lvl=1`（输入面 LB0 = 80×80×3）、`tile(ir,ic)=(0,0)`、看 `PE(5,5)`（= 第 55 号 PE）。

---

## 0. 先看输入面（LB0）

源像素按 `n = y*160 + x` 线性递增：`R5=n&31, G6=(n>>2)&63, B5=(n>>1)&31`，
再按位复制展开到 8bit：`R=8*R5+(R5&7)`、`G=4*G6+((G6>>1)&3)`、`B=8*B5+(B5&7)`。
2×2 max 池化（步长 2，无 padding，因为图是偶数）→ LB0。

`LB0(0,0) = 0x000080`（R=128,G=0,B=0，是那块 2×2 里 R 最大的像素）。

tile(0,0) 的 12×12 窗口起点 = `(10*0-1, 10*0-1) = (-1,-1)`，越界反射：

```
窗口行 index : -1  0  1  2 ... 10
实际取面行   :  1  0  1  2 ... 10      (行 -1 -> 1)
窗口列同理   :  1  0  1  2 ... 10
```
（`N -> N-2`：若 tile 在最后一行，窗口行 80 会取 78。）

波形的 `3_lb0_win` 组里 `lb0_win[R*12+C]` 就是这条窗口，`win_ch` 决定读哪个通道。

---

## 1. 深度卷积（复用模式，逐通道 12 拍）

`PE(5,5)` 负责输出面像素 `(5,5)`，它的 3×3 窗口 = 面像素 `(4..6, 4..6)`。
本 tile 通道 0 的这 9 个值（光栅序）是：

```
[164 173 182]
[164 173 182]
[164 173 182]
```

执行器对通道 c 的 12 拍（`dcy = 0..11`，`est=E_DW`）：

| dcy | 动作 | 波形上能看到 |
|-----|------|--------------|
| 0 | `fm_wen=fm_start=1`：12×12 窗口进 feature_map 并 start；权重 `k=0` | `fm_wen=1`, `fm_start=1` |
| 1..8 | 依次喂权重 `k=1..8`（本设计 dw 同通道 9 抽头同权，所以看不出来；换成真实非对称核就是这 9 拍） | `dwk`, `rom_addr`, `rom_d` |
| 3..11 | 9 个抽头依次进入累加器 | `peo[55]` 逐个台阶 |
| 11 | 累加完成 | `peo[55] = 1557` |
| 11 沿 | 捕获 `dwc[c][*]`，**同一沿**装载下一通道窗口+start | `dwc[0][55] <= 1557` |

`peo[55]` 实测台阶：

```
dcy :  3    4    5    6    7    8    9    10   11
抽头: 164  173  182  164  173  182  164  173  182
peo : 164  337  519  683  856 1038 1202 1375 1557
                                       ↑ 1375 时还差最后一个 182
```

通道 0/1/2 的结果（`dwc[c][55]`，18bit 未量化）：

```
dwc[0][55] = 1557      (窗口 164/173/182 的 9 抽头和)
dwc[1][55] = 0         (这个像素在第 1 通道的窗口正好全 0，黄金模型也是 0)
dwc[2][55] = 0
```

> 注意：`dwc` 是 18bit **不量化**直接喂点卷积（和老设计一致）。

## 2. 1×1 点卷积（连续 present）

对每个输出通道 `oc`，把 `CIN` 个输入通道的 `dwc[c][px]` 依次 present，
每个 PE 拿到的是**自己那个像素**的值，权重全体广播。

本设计权重（见 `mb2_wdef.vh`）：`w(oc,ic) = 4` 当 `ic == oc % CIN`；`= 1` 当 `ic == (oc+1) % CIN`；其余 0。

`oc=0` 时：`w(0,0)=4, w(0,1)=1, w(0,2)=0`。

`PE(55)`（像素 (5,5)）在 `oc=0` 的累加：

```
present 拍 T0   : A=dwc[0][55]=1557, B=4   → 乘积 6228
present 拍 T0+1 : A=dwc[1][55]=0,    B=1   → 乘积 0
present 拍 T0+2 : A=dwc[2][55]=0,    B=0   → 乘积 0
```
流水（实测 `mb2_cal_b_tb`：present 后第 2 拍出乘积）：

| 拍 | 事件 | 信号 |
|----|------|------|
| T | present | `pw_pre=1, pc_oc=0, pc_c=0` |
| T+2 | 乘积 | `peo[55]=6228` |
| T+3 | `pacc` 累加（`s3c==0` 时是**覆盖**，不是加） | `pacc[55] <= 6228` |
| T+1/T+2/T+3 | 后续通道累加 | `pacc[55] = 6228+0+0 = 6228` |
| T+4 | 量化写 `blk`（`s4c==CIN-1`） | `blk[0][55] <= (6228+128)>>8 = 24` |

量化：`q = clamp((pacc + 128) >>> 8, 0, 255)`（Q0.8 权重，+128 是四舍五入，负数夹到 0）。

同一 tile 的 16 个 oc 都算完 → `blk[0..15][0..99]` 全部就位
（第 1 级输出的 `L1O(0,0)` 16 个通道 = `[19,5,0,19,5,0,19,5,0,19,5,0,19,5,0,19]`，
这种"3 个一循环"就是上面稀疏权重 `oc%3` 的直接体现，通道接线错一位就会看出来）。

## 3. 写回目标面

`E_WR` 用 100 拍把 `blk` 写成 10×10：

```
we_k = 0..99
目标行 we_r = 10*ir + we_k/10
目标列 we_c = 10*ic + we_k%10
整字数据   = {blk[COUT-1][we_k], ..., blk[1][we_k], blk[0][we_k]}
```
第 1 级写 L1O（16 通道 = 128bit/字），第 2 级写 L2O（32 通道 = 256bit），第 3 级写 L3O（64 通道 = 512bit）。

---

## 4. 池化（2×2 max，步长 2）

`L1O(80×80×16) → LB1(40×40×16)`：每个输出像素读源面 `(2r,2c)(2r,2c+1)(2r+1,2c)(2r+1,2c+1)`
四整字，**逐通道**取 max。因为整字存（一个像素的全部通道在一个字里），
一拍能同时比较 16（或 32）个通道，只需要 4 拍读 + 1 拍写 = 5 拍/像素（1600 像素 = 8000 拍）。

`LB1(0,0)` 实测 = `L1O(0,0)` 同值（角上那个 2×2 里它就是最大）。

---

## 5. 三级串起来的结果（160×160 输入）

```
DDR 顺序读一遍 (160×160 行, 每行 20 个 128bit beat)
  -> 2x2max -> LB0 80x80x3     (逐字节 0 mismatch)
  -> dw+pw  -> L1O 80x80x16    (0)
  -> 2x2max -> LB1 40x40x16    (0)
  -> dw+pw  -> L2O 40x40x32    (0)
  -> 2x2max -> LB2 20x20x32    (0)
  -> dw+pw  -> L3O 20x20x64    (0)   ★前端结果
共 54990 拍 ≈ 0.27ms @200MHz
```
第 3 级输出 `L3O(0,0)` 的 64 个通道（8bit）实测开头：
`ch63..ch56 = [2,1,0,1,1,0,2,1]`。

对应 640×480 时最后一级是 `80×60×64`，正好是第一个残差块的输入。
